# Logos

This group is **empty on purpose**. The source for this system is a written specification, not artwork, and a real company's mark is never reconstructed from a description — so no Arc, wordmark or hexagon lockup file has been generated here.

Marketing should upload the vector originals into this group:

| File | What it is |
|---|---|
| `alqawsan-horizontal-color.svg` | Arc + Arabic wordmark + English wordmark, full colour, for light grounds |
| `alqawsan-horizontal-white.svg` | The same lockup reversed, for navy, indigo, orange and photographs |
| `alqawsan-horizontal-navy.svg` | Single-ink navy, for stamps, fax and embossing |
| `alqawsan-arc.svg` | The Arc symbol alone — favicon, app icon, slide corner, avatar, watermark |
| `alqawsan-hexagon-lockup.svg` | The logo inside the hexagon outline, for stationery |
| `alqawsan-group-lockup.svg` | The three-hexagon group lockup with CAS Development and the manufacturing partner |

Each one as SVG with outlined text and, for print, a CMYK PDF or EPS beside it.

Two things to know when they arrive. An SVG shown on this page renders through `<img>`, so it cannot inherit colour from the page — a single-ink mark has to carry its own ink, which is why the navy and white versions are separate files rather than one recoloured at use. And the Arc is always the `gradient-arc` ramp, solid white, or solid navy; it is never recoloured to suit a layout.

Placement, clear space, minimum sizes and the don'ts are in *Logo & the hexagon motif*.

Until the files are here, set the name in `h3` / `ar-h3` in `text-heading` and leave the logo zone clear.
