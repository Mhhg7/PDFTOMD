# Checklist & corrections

## Before publishing

- [ ] Only palette tokens and the three approved gradients are used — no ad-hoc colour
- [ ] Correct fonts per language; Arabic set one step up; no Arabic letter-spacing, no Arabic italics
- [ ] Logo at the reading-start corner, clear space respected, the right version for the ground
- [ ] Contrast checked against the table in the brand book — especially anything sitting on orange
- [ ] Focus is visible on every interactive control: orange ring **and** the navy border change
- [ ] RTL mirrored properly; numerals, URLs, phone numbers and email addresses stay LTR
- [ ] Arabic full stops fall at the end of the line, not the start
- [ ] Brand name, address and entity names spelled as in the brand book
- [ ] One hexagon focal cluster at most; pattern at or below `opacity-pattern-max`, and `opacity-watermark` behind text
- [ ] Every status carries a word, not just a colour
- [ ] Facts and numbers current and sourced; no medical outcome claims
- [ ] Both languages carry equal visual weight

## Corrections to the existing materials

| Found in current materials | Correct going forward |
|---|---|
| "Al-Qawsan Scientific Office", "Alkawsan" | **Al-Qawsan Scientific Bureau** |
| "Qadisiya" | **Qadisiyah District** |
| "Cas Development" | **CAS Development** |
| Arial / Tahoma / Calibri mixed through the slides | Montserrat + Inter, Cairo + IBM Plex Sans Arabic |
| Arabic full stops at the start of a line | Set the paragraph direction to RTL — right-alignment alone does not fix it |
| White body text on orange cards | `on-accent` (navy) body text on orange; white only at 24px bold and above |
| Yellow wave on the door sign | White sign with a `gradient-arc` bar at the foot |
| Mirrored reflections under partner logos | Flat white tiles at `radius-lg`, equal size |
| 3D clip-art figure on the onboarding cover | Real team or warehouse photography under a navy overlay |
| Several blues used interchangeably (#1E3A5F, #5B6BB5 …) | `navy-800` is primary; `indigo-600` is the only secondary blue |
| Arc redrawn or recoloured per deck | One set of vector originals in the **Logos** asset group |
